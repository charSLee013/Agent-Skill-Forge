# 宪法模板(填空式)

把 `{{ }}` 逐个填掉,删掉用不到的条款,得到本次任务的宪法。含糊的填空(如"尽量快一些")是违宪的根源,每一格都要填成可判定的数值或路径。三条标注 ⚠ 的条款必须逐条向用户过目,不允许静默采用默认值。

---

```markdown
# {{任务名}} 研究宪法 v{{1}}

## 0. 目标与裁判

- 真实目标:{{一句话,与"分数"的关系写清楚}}
- 主指标:{{名称}},{{越低越好 / 越高越好}}
- 裁判:{{脚本/命令 + 怎么跑}},版本 v{{n}}
- 噪声地板:{{数值}}(来源:基线跑 {{k}} 次的 2σ)
- 判定规则:提升 ≥ 地板 → keep;|变化| < 地板 → 平局(discard);crash 按第 3 节处置
- 评估旋转:{{每次从题池随机抽 n 题 / 按实验序号轮换子集}};锚集(若有)只用于报告,不参与判定

## 1. 变异面

- 开放(一切手段皆可):{{路径列表}} —— 含构建、配置、目录结构、工具链
- 冻结(修改即违规):裁判代码 {{路径}}、评估数据 {{路径}}、评估协议本文
- 发现裁判可刷分 → 停止实验 → 报告人类 → 人类修补 → 裁判版本 +1;漏洞存续期分数一律作废

## 2. 变异的产出方式

- 每次变异一个 commit,描述写进 commit message
- 账本:{{results.tsv 路径}},只追加,不进 git:commit | 分数 | 成本 | status(keep/discard/crash) | 一句话描述
- 首个实验固定为基线:不改任何代码跑一次裁判

## 3. 选择压力

- keep:提升 ≥ 噪声地板 → 分支前进
- discard:平局或退步 → git reset 回分支起点
- crash:笔误型缺陷(漏 import、路径错)修复后重跑一次;想法破产 → 记账放弃
- 简约准则:主指标平局时,机制更少者胜——删代码达成的等价提升必须 keep,加机制换来的贴地提升应当 discard

## 4. ⚠ 反退化条款(三选不全即违宪)

### 4a. 无聊轴黑名单
- 未来 {{M}} 个实验禁碰:{{当前任务里等价于"调参"的改动类别,枚举具体类别}}

### 4b. 变异组合配额
- 按 {{架构 / 算法 / 数据 / 目标函数}} 四类轮流开采,每类连续开采不超过 {{1}} 轮
- 与最近 {{K}} 个保留变异雷同的方案按平局处理(雷同的判定:改动类别与作用机制相同)

### 4c. ⚠ 探索预算(对付"短期降、长期好")
- 每 {{N}} 个实验允许 1 次 wild mutation:大结构改动允许暂时回撤 ≤ {{回撤阈值}},记在侧分支 `research/{{tag}}-wild`,不参与主线 advance-or-reset
- wild 分支的转正条件:{{在其上追加 ≤ n 个实验后追平或超越主线最优}}

## 5. ⚠ 运行策略(二选一,不允许混用)

- [ ] NEVER STOP:循环运行直到手动打断;不请示"要继续吗",不宣告"这是不是好的停止点"
- [ ] 早停(用户设定,优先于一切默认):实验数上限 {{N}} / 墙钟上限 {{T}} / 熔断:连续 {{M}} 个实验无 keep → 停止,报告"地形可能已采尽或裁判可能失真"

进度播报:每约 10 个实验输出一行(当前最优 | keep-rate | 账本行数),播报不打断循环。

## 6. 审计

- 红队攻击:第 {{1}} 个实验前、此后每 {{30}} 个 keep 攻击一次裁判
- 人工抽检:每 {{20}} 个实验向用户提交抽检包(delta 最大 k 条 + 贴噪声地板最可疑 k 条)
- 裁判修补历史:{{记录位置}}
```

---

## 填空时的常见错误

1. **地板写成拍脑袋的整数**。地板必须来自第 0 节的基线实测;填不出来就先去跑 k 次基线,宪法的其他格子可以先填,这一格不行。
2. **无聊轴黑名单空着**。"这次先不禁"几乎必然导致循环滑向该任务里最顺手的旋钮。拿不准禁什么,就按"改了之后代码 diff 少于一行的优化类改动"先兜底。
3. **探索预算与 NEVER STOP 组合时漏转正条件**。wild 分支没有转正条件 = 永远挂在侧分支的僵尸变异工厂。转正条件要可判定(时间盒 + 分数线)。
4. **早停选了却和熔断混淆**。实验数/墙钟上限是"到了就停,正常交付";熔断是"异常信号触发,报告地形或裁判问题再决定"。两者可以同时设,语义不同,账本汇报方式也不同。

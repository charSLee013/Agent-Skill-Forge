# Productivity

Planning, learning, communication, and writing tools. `grilling` clarifies
important choices and supports continued work under the user's authorization.
`wait-what` repairs one explanation in the user's language without changing
later conversation style.

| Skill | Invocation | Purpose |
|---|---|---|
| [grilling](./grilling/SKILL.md) | Model or user | Resolve important choices and continue the already requested work. |
| [humanizer](./humanizer/SKILL.md) | Model or user | Rewrite existing prose naturally while preserving claims and voice. |
| [teach](./teach/SKILL.md) | Model or user | Build a complete static HTML course with supporting Markdown. |
| [wait-what](./wait-what/SKILL.md) | User only | Re-explain the previous response in the user's language for one turn. |
| [handoff](./handoff/SKILL.md) | User only | Prepare a continuation document for another session. |
| [to-questionnaire](./to-questionnaire/SKILL.md) | User only | Write a questionnaire for one informed recipient. |
| [i-have-adhd](./i-have-adhd/SKILL.md) | User only | Enable an explicitly selected action-first communication mode. |
| [prepare-goals](./prepare-goals/SKILL.md) | User only | Prepare bounded Goal launchers for clear long-running work. |
| [prose-standard](./prose-standard/SKILL.md) | User only | Review or edit technical prose while preserving its complete contract. |
| [trim-cot-leakage](./trim-cot-leakage/SKILL.md) | User only | Remove authoring-session residue while preserving durable facts. |
| [doc-standards](./doc-standards/SKILL.md) | User only | Audit documentation ownership, placement, and agreement with reality. |
| [writing-great-skills](./writing-great-skills/SKILL.md) | User only | Write predictable skills and agent-consumed documentation. |

Model-invoked skills can be selected from task intent. Manual communication
modes and specialized editorial workflows remain explicitly selected.
Reading a shared reference does not invoke its owning workflow.

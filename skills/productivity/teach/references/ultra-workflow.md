# Ultra Workflow

Read this file after the user confirms Ultra. Ultra adds comprehensive domain coverage, specialist collaboration, tracer approval, and independent review to the shared Teach quality floor.

## Shared Brief

Create one brief from the Course Contract. Include learner and prerequisite gap, target capability, main trunk, scope, evidence expectations, editorial direction, visual thesis, representation inventory, publication target, page topology, tracer, and four review gates.

Every specialist works from this brief. The primary Agent owns synthesis and final decisions.

## Temporary Workspace

Use:

```text
${TMPDIR:-/tmp}/teach-ultra-{unique-id}/
  research/
  drafts/
  reviews/
  screenshots/
  tests/
```

Keep raw research, drafts, feedback, screenshots, browser profiles, logs, and fixtures there. Promote only declared publication artifacts. Clean the owned directory after final verification.

## Phase 0: Architecture Sketch

Before dispatching any specialist, fill the Course Contract and `../templates/structured-object-map.md` yourself and present them for one user calibration on the main trunk, scope, and evidence ecology.

Specialist work is the expensive part of Ultra. Confirming direction first means a redirected trunk costs one exchange rather than a discarded round of parallel research.

## Phase 1: Discovery

Dispatch roles according to the subject:

- **Domain Expert**: authentic tasks, standards, decisions, and failure diagnoses;
- **Evidence Researcher**: sources, facts, data, formulas, standards, and provenance;
- **Learning Architect**: prerequisites, progression, coverage, practice, and transfer;
- **Editorial Director**: voice, terminology, lesson arcs, paragraph coherence, and density;
- **Mechanism Auditor**: formulas, processes, state changes, boundaries, and examples;
- **Assessment Designer**: feedback, capstone, and rubric;
- **Visual and Frontend Director**: visual thesis, representations, motion grammar, responsive behavior, and state models and reduced-motion behavior.

The primary Agent resolves contradictions and integrates one architecture. Complete discovery when every Course Contract field has evidence and every prerequisite gap has a bridge.

## Phase 2: Integrated Architecture

Synthesize the main trunk, dependency maps, coverage layers, page responsibilities, evidence map, editorial system, visual thesis, mechanism specs, practice progression, capstone, and publication topology.

Complete the phase when each page has one learning responsibility, assigned content objects, an editorial arc, representation purposes, evidence, and a next capability.

## Phase 3: Tracer

Build the course map, densest representative lesson, one reference or deep-dive page, one key mechanism visual, and an applicable complete practice or interaction state.

Choose a tracer that exercises the hardest combination of long-form reading, technical reconstruction, evidence, practice, responsive layout, navigation, and enhancement. Run all review gates with fresh, neutral reviewers. Repair findings and rerun affected gates.

Present the passing tracer and Course Contract for one user calibration. Expand only after that calibration.

## Phase 4: Expansion

Delegate coherent learning arcs with explicit page responsibilities. Give contributors the shared brief, accepted tracer, vocabulary, evidence map, editorial direction, visual system, and navigation contract.

The primary Agent checks cross-page terminology, paragraph handoffs, prerequisite continuity, evidence roles, visual grammar, and publication topology. Complete expansion when every declared artifact and content object exists.

## Phase 5: Final Review

Use fresh reviewers for Publication; Learning, Editorial, and Fidelity; Visual System; and Interaction and Motion. Keep prior diagnoses and expected conclusions outside their prompts.

Repair findings by learner impact, rerun affected checks, verify the declared publication target, and clean the owned workspace.

## Runtime Adaptation

Use parallel specialists when available and the same roles sequentially otherwise. Preserve the quality bar and report the actual review independence.
